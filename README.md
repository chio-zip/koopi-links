# koopi-links

A one-page bridge for Koopi share links. WhatsApp only turns `https://` addresses into links, so Koopi shares
`https://chio-zip.github.io/koopi-links/?c=<collection id>` (or `?p=<piece id>`). The page opens the app with
`koopi://collection?id=<id>` (or `koopi://?piece=<id>`).

It holds no data and no code beyond this page. The address carries only an id, never a name.
